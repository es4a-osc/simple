# SQLite 数据库示例

本使用说明依据当前运行库 `SQLite数据库` 接口与配套示例核对（2026-10-18），适用于应用本地 SQLite 数据库操作，无需网络或存储权限。

## 运行示例

在 ES4A 添加本目录的 [project.properties](project.properties)，使用包含 `SQLite数据库` 的配套运行库构建。示例代码见[主窗口](src/simple/examples/sqlite/主窗口.simple)。

点击“运行演示与自检”，在应用私有数据库目录使用专用 `es4a-sqlite-demo.db` 和 `es4a-sqlite-other.db`。每次只重建示例自有数据表，不删除其它数据库文件。

自检覆盖增删改查、范围偏移、统计、完整表名列表、引号标识符、NULL 文本、双实例隔离、关闭重开及数据库错误捕获；成功显示检查数量与实际查询结果。

## 连接与路径

`SQLite数据库` 是普通对象，通过“创建”获得实例；每个实例独立管理一个连接。相对路径只接受文件名，位于应用私有数据库目录；绝对路径的访问能力由 Android 存储规则决定。

`打开数据库` 在文件不存在时创建；`创建数据库` 只创建并初始化新文件，不自动打开本实例连接，文件已存在时返回假且不覆盖。打开新数据库成功后关闭本实例的原连接，打开失败保留原连接。

同步调用放在后台线程执行，再通过窗口的反馈消息事件显示结果；数据库对象自身没有事件。成功和失败分支都应显式关闭连接，离开过程不会自动关闭，重复关闭允许执行。

## 查询结果与 SQL

查询文本在每列末尾追加列分隔符、每行末尾追加行分隔符，包括最后一列和最后一行。例如列分隔符为 `|`、行分隔符为换行时，一条记录返回 `1|张三|\n`。无记录返回空文本；SQL NULL 返回文本 `null`，无法与内容为 `null` 的普通文本区分，也不适合无损表示二进制列。

表名和字段名参数按单个标识符处理，不是 SQL 表达式。字段定义、记录值、修改字段和筛选条件仍是 SQL 片段，文本值中的单引号须写成两个单引号，例如 `'李四''改'`。空删除或修改条件会被拒绝；需要全部记录时明确传入 `1=1`，或执行完整 SQL。

范围查询未指定排序。需要稳定分页时，使用 `数据库查询` 并显式写入 `ORDER BY` 与 `LIMIT`。当前接口不提供单独的参数绑定、事务或加密功能，也不连接远程数据库；完整方法及参数可在 ES4A 运行库视图中查看。

## 错误与资源

路径、未打开连接及 SQL 操作失败会抛出“数据库错误”，通过 `位于 错误` 中的 `分支 数据库错误` 捕获。空结果或表不存在等正常返回值不等于操作失败。

查询游标由内部释放，连接仍由使用者负责关闭。同一个对象的每次调用串行执行，但连续多次调用不构成事务；不要把同一对象交给多个后台任务组合需要整体原子性的操作。
