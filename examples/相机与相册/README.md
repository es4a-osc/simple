# 相机与相册

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

调用系统相机、选择照片、预览结果及读取旋转信息。

运行准备与完整目录见[项目说明](../../README.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/camera/主窗口.simple)。

1. 先请求拍摄所需权限，确认本应用可写的输出路径。
2. 拍照并等待完成事件；取消拍摄后可重新尝试。
3. 通过系统相册选一张照片，观察预览与返回路径。

默认输出是常见主用户安装的应用私有路径；多用户、工作资料或其他安装布局应改为本应用实际可写路径。拍摄需要系统相机，选择图片可能返回复制到缓存的路径；取消选择不伪造成功结果。读取 EXIF 旋转角度不会自动旋转图片。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
