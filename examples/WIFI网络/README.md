# WIFI网络

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

读取当前 Wi-Fi 信息，申请定位权限后扫描附近网络。

运行准备与完整目录见[项目说明](../../README.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/wifi/主窗口.simple)。

1. 在系统 Wi-Fi 设置连接网络。
2. 读取网络信息，对比系统显示。
3. 授予定位权限后请求扫描，等待完成事件。
4. 拒绝权限、关闭 Wi-Fi 或连续扫描时观察失败提示。

本例不自动增删已保存网络、不修改静态 IP 或创建热点。扫描结果是当前组件约定的文本格式，字段用 *、记录用 / 分隔；不将它当成通用结构化格式。信号强度是 0-4 等级，不是 dBm；系统可能隐藏 SSID/BSSID，扫描也可能被节流。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
