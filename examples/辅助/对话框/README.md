# 对话框

演示确认、选择、输入、日期、时间、进度和自定义内容对话框。

运行准备见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。页面可上下滚动。

1. 打开日期／时间框，分别验证确认、取消、返回和点击框外；页面持续显示是否确认及结果。取消返回假，输出保持不变。
2. 指定初值为上海时区的 `2024-02-29 23:45:56`；日期框只替换年月日，时间框保留日期并将秒、毫秒归零。示例断言初值保持不变。
3. 默认时间框和“系统时制”遵循设备设置；勾选框只影响“指定初值与时制”的显示，不修改系统设置。12 小时制确认后的小时仍按 0–23 读取。
4. 分别打开确认、是否、单选、多选和输入框，观察确认或取消后的返回结果。
5. 打开进度框，等待自动关闭后再次打开。
6. 打开自定义对话框，修改文本并确认，观察返回的编辑内容。

日期、时间框返回是否确认的逻辑值，并通过最后一个传址参数输出 `日期时间型`；确认写入新对象，取消保持原输出不变，初值与输出可使用同一变量。先判断返回值再使用结果，不用日期的 `= 空` 比较判定取消。选择框在界面事件中调用，等待关闭后继续执行，不放入错误处理语句中。日期初值须处于平台选择器支持的范围，界面样式随系统主题变化。

自定义内容见 [对话框内容.simple](src/simple/examples/dialogs/对话框内容.simple)。
