# 文本与数组

演示文本传址修改、查找、标记提取、数组增删排序，以及 UCS2、URL、Base64 和字符集转换。无需联网或额外权限。

在 ES4A 添加本目录的 [project.properties](project.properties)，使用包含这些接口的运行库编译运行。源码见[主窗口](src/simple/examples/textarrays/主窗口.simple)，项目使用说明见 [项目开发文档](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。

依次点击按钮，输出区会显示转换前后内容及自检结果：

- 运行演示与自检：修改文本、分割和筛选数组。
- UCS2 转义与还原：覆盖前导零、中文、换行和表情，保留原有 UCS2 接口名称。
- URL 参数编码与解码：比较 UTF-8、GBK，验证空格、加号和百分号的还原。
- Base64 字节编码与解码：文本先转 UTF-8 字节，再编码和还原，检查填充及换行输入。
- UTF-8 与 GBK 字节转换：同一段“中文”分别得到 6 和 4 个字节。
- 无效输入与空内容自检：捕获不完整转义、无效字符集等错误，验证空内容正常返回空结果。
- 文本边界、替换与标记提取：区分字符长度和字节数，验证全空格、字面替换、区间替换和跨行标记内容。
- 数组增删、排序与文本分割：增删返回相同元素类型的新数组，排序原地修改，默认分割保留末尾空项。

字符代码转换（`代码`、`字符`）、`分割文本` 和 `连接数组文本` 归入“文本操作”；数组的排序、筛选、增删仍归“数组操作”。字节合并统一使用 `字节集操作.合并字节集`，保留输入顺序并返回独立副本。

查找位置和数组索引从 0 开始；取数组下标的维度参数从 1 开始。带数量参数的分割文本将其作为最大返回成员数，必须大于零；省略数量时分割全部内容，均保留末尾空项。过滤数组文本沿用去重规则，并按首次出现的顺序返回。删首尾空、到大写、子文本替换、替换文本区间通过传址修改变量，不返回新文本。

取字符数按 UTF-16 单元计数，表情等补充字符占两个单元；取文本字节数按明确字符集计数。标记提取按字面内容匹配，不处理嵌套。子文本替换只匹配原有内容，不再次匹配新写入文本；空查找文本匹配原文边界。

插入、追加和删除成员保留原数组，结果需接回变量；这三个接口沿用失败返回空的约定。数组排序用于整数数组，文本数组排序用于文本数组；二者直接修改原数组，文本按字典顺序排序。

未指定字符集时使用 UTF-8。文本与字节转换时，无法表示的字符或无效字节按字符集的默认替换规则处理。

URL 接口用于参数值，不能直接编码完整网址；空格编码为加号，原有加号编码为 %2B。Base64 使用标准字母表，编码不换行；解码沿用 Android 的宽松规则，允许换行及省略末尾填充，不作为严格格式校验或加密功能。

相关平台规则：[URL 参数编码](https://developer.android.com/reference/java/net/URLEncoder)、[Base64](https://developer.android.com/reference/android/util/Base64)。
