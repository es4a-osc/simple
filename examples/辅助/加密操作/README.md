# 加密操作示例

打开本目录的 `project.properties`，输入明文和密钥，再选择 RC4、DES 或 Authcode。点击“运行固定向量与格式自检”可检查已知摘要、密文及中文处理。无需网络或设备权限。

RC4 和 DES 用于既有格式互通：文本采用 GBK，DES 密钥须为 8 字节且使用固定 IV。Authcode 采用 UTF-8 和随机前缀；校验失败返回“2”，但“2”也可能是合法明文。

`RC4加密2` 返回十六进制字符的 ASCII 字节，`RC4解密2` 接收原始密文字节，两者不能直接成对使用；固定向量按钮展示这个差异。Base64 等编码方法统一由 `编码转换` 提供。
