# 日期时间

文档类型：运行库使用示例。核对日期：2026-10-17；依据：当前 Simple 编译器、运行库源码与本项目。

演示格式化、时间戳、时区、日期增减、固定时长间隔及当前日期时间文本。

在 ES4A 添加本目录的 [project.properties](project.properties)，点击“运行演示与自检”。[主窗口源码](src/simple/examples/datetime/主窗口.simple)展示上海时间、一星期增量、正负间隔和同一时刻的 UTC 显示；再次点击可重复自检。

- `取月份` 返回 0–11，建议与月份常量比较；`增减时间`、`置时间时区` 修改传入对象，切换时区不会改变时间戳。
- `取时间间隔` 返回结束减去开始的固定时长差，年按 365 天、月按 30 天、星期按 7 天、天按 24 小时折算，不足单位向零截断；这不是日历年月差。
- `取现行日期文本("-")`、`取现行时间文本(":")` 按设备默认时区生成文本，分隔符作为普通文本使用，空文本表示不分隔。
- `时间戳到时间文本` 接受 10 位秒或 13 位毫秒时间戳文本，按设备默认时区输出；空值或其他长度返回空文本，正确长度的非法数值会抛出异常。原有数值时间戳接口始终使用毫秒。
- 日期解析保留宽松处理及允许尾随文本的行为，不作为严格日期校验器。

验证状态：当前源码已通过 34 项日期测试、JavaDoc 检查和 APK 编译；Android 14 / API 34 模拟器已验证自检及重复运行，真机尚未验证。
