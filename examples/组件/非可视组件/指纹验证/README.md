# 指纹验证示例

需要 Android 6.0（API 23）及以上、可供应用使用的指纹硬件、安全锁屏和已录入指纹。USE_FINGERPRINT 是普通清单权限，示例不弹出运行时权限申请。低版本或缺少硬件时显示明确状态，应用仍可打开。

1. 添加本目录的 project.properties，编译运行后点击“查询可用状态”。
2. 条件不满足时点击“打开安全设置”，按设备提供的设置录入指纹；返回应用后重新查询。
3. 点击“开始验证”，触摸设备指纹传感器。匹配成功结束验证，未匹配或采集提示允许继续尝试。
4. 验证中再次点击开始不会替换原请求；点击取消或离开应用会结束验证，取消后可重新开始。
5. 点击“销毁组件”后查询和开始均报告已销毁，不再收到结果事件；重新打开应用可再次演示。

界面底部显示事件序号和系统说明。临时锁定、永久锁定及传感器占用由系统错误报告，查询状态不能预先排除它们。此示例只验证已录入指纹，不读取指纹图像或身份信息，不提供账号密码、人脸识别或密钥解锁功能。
