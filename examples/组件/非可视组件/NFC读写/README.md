# NFC读写

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

初始化 NFC、读取标签文本和卡号，并准备 NDEF 文本写入。

运行准备与完整目录见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/nfc/主窗口.simple)。

1. 开启手机 NFC 后初始化。
2. 读取普通 NDEF 标签，查看文本和 ID。
3. 用可覆盖的测试标签尝试写入，再切到读取模式验证。
4. 退出或切换后台后，观察组件生命周期行为。

初始化返回 1 不支持、2 未开启、3 初始化成功。只演示普通可写 NDEF 测试标签，不应对门禁卡、支付卡等受保护用途做可写承诺。切到写入模式不等于标签已写入，必须读回验证；卡号是标签标识转换结果。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
