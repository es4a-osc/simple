# 通讯录

读取系统通讯录，并用本例创建的临时数据演示联系人及分组操作，不直接访问 SIM 卡。

## 使用

在 ES4A 添加 [project.properties](project.properties)，使用当前 SDK 构建运行。源码见[主窗口](src/simple/examples/contacts/主窗口.simple)，项目说明见 [项目开发文档](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。

1. 未授权时点击同步或异步读取，查看明确的失败信息。
2. 点击申请通讯录权限，在系统提示中选择允许或拒绝；只有读取及写入均授权才能运行数据自检。
3. 同步、异步读取仅显示记录数量，不输出设备已有联系人的姓名和号码。异步按钮还会发出第二次请求，检查同一组件拒绝重叠读取。
4. 勾选确认后运行自检。示例创建两条同名、不同号码的临时联系人，验证按原始编号删除第一条后第二条仍存在；同时验证分组创建、枚举、重复添加、读取、移除和删除分组后保留联系人。
5. 自检结束会清理本例创建的联系人及分组。失败时可重试清理；未完成清理前不要关闭窗口，临时编号只保存在本次窗口中。异常退出后如需人工清理，按本轮显示名称 `ES4A测试_<时间戳>` 精确核对，不按宽泛名称删除。

## 数据与错误

`取联系人` 和 `取分组联系人` 返回集合，每项是四列文本数组：

| 索引 | 内容 |
| --- | --- |
| 0 | 原始联系人编号，供删除及分组操作使用 |
| 1 | 姓名 |
| 2 | 电话号码，无号码时为空文本；多个号码会产生多项 |
| 3 | Android 聚合联系人编号，仅供识别系统合并关系 |

`取联系人分组` 的每项依次为分组编号、名称、账号名称、账号类型、数据集，均为文本。编号不能互换，不应长期缓存编号；重新查询后再修改。删除一个原始联系人可能同步到其所属账号，并不只是删除当前 APK 中的副本。

同步操作失败返回空集合、空文本或假，并提供 `最近错误`；空集合也可能表示成功但没有数据，须同时检查错误文本。异步方法返回真只表示请求被接受，最终以 `取联系人完毕` 的结果、请求标记和错误信息为准。

本地分组的账号名称和类型传空文本。设备可能不支持本地分组；该分支会明确显示创建失败，不算分组测试通过。账号分组要求原始联系人、分组的账号及数据集一致，不会自动创建系统账号。
