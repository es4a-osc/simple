# UDP数据报

绑定本地 UDP 端口，定向发送或广播，并显示数据报来源。

运行准备见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 保留默认配置，点击“开始监听”，稍后发送 `72 105 10`，观察本机接收日志。
2. 修改发送内容，使用空白分隔的 `0～255` 十进制字节，每次最多 1024 个。
3. 跨设备时各自监听一个端口，目标填写对方的地址和端口。
4. 目标地址留空可发送广播；结束时停止监听。

组件没有绑定成功回调，发起监听后需通过实际接收验证；发送方法返回也不保证对端收到。广播可达性取决于网络与设备设置。
