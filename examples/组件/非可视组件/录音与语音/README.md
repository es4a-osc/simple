# 录音与语音

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

麦克风录音、播放录音，以及系统语音识别和朗读。

运行准备与完整目录见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/speech/主窗口.simple)。

1. 授予录音权限，确认输出路径。
2. 录制数秒后停止，再播放检查文件。
3. 输入文本请求朗读；安装系统语音识别应用后尝试识别。
4. 切到后台确认示例停止录音。

默认录音路径为常见主用户安装的应用私有目录，多用户或其他安装布局需调整为实际可写路径。父目录会自动创建，文件会被覆盖；启动失败后释放资源并进入错误分支，停止失败也会释放资源并尝试删除无效文件，可以重新开始录音。私有路径只需麦克风权限；旧版系统的共享存储路径还需相应存储权限。语音识别依赖系统应用，朗读依赖 TTS 语言包；录音时不要同时播放或朗读。

验证状态：已在 Android 14（API 34）完成基本录音、解码播放、无效路径后重试和后台停止的 APK 自动化验证；prepare/stop 的原生异常分支及系统语音识别、朗读尚未逐项实测。
