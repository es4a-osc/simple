# 光线与距离

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

读取照度、接近距离并控制距离监听。

运行准备与完整目录见[示例入口](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/lightsensors/主窗口.simple)。

1. 在真实设备运行，遮挡和移开环境光传感器。
2. 靠近、移开距离传感器，比较距离改变和阈值事件。
3. 暂停监听后再启用，观察读数是否恢复。

需要对应硬件，无硬件或监听失败时不会制造读数。光线是否有效仅表示存在传感器；距离可用表示监听状态。距离阈值设为 1 cm，不将读数 0 视为硬件不存在。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
