# 摄像预览

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

在窗口预览摄像头、对焦，并取得 JPEG 照片字节。

运行准备与完整目录见[示例入口](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/preview/主窗口.simple)。

1. 授予相机权限后打开预览。
2. 等待预览画面出现，再对焦和获取照片字节。
3. 后台再返回，检查已关闭并可重新打开预览。

摄像头类型 1 前置、2 后置；尺寸只是选择请求，设备可采用支持的尺寸。拍摄格式 1 JPEG、2 PNG，质量 0-100。开始请求并不证明预览已成功。页面进入后台会关闭摄像头，回来后显式重新打开，不在后台继续占用相机。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
