# TCP客户端

连接 TCP 服务端，发送字节并显示回显。

运行准备见[项目说明](../../README.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 先运行配套 TCP 服务端并监听 `5001` 端口。
2. 填写地址和端口，点击连接，等待“连接成功”。
3. 保留 `72 105 10` 或输入自己的十进制字节，点击发送并比较回显。
4. 尝试 `0 127 128 255`，观察无符号字节显示；结束后断开连接。

配套示例：[TCP服务端](../TCP服务端/README.md)。

TCP 是字节流，回显可能分多次到达。“已调用发送”表示发送方法已返回，对端接收结果以接收日志为准。
