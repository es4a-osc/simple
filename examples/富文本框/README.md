# 富文本框示例

使用当前运行库编译并运行本目录的 project.properties。

- 直接输入或长按选择文字，再点击加粗、红色、下划线、清除格式。
- “选中开头”便于体验工具栏；“读取选区”显示实际索引和纯文本。
- “样式演示”展示字号、字体、颜色、删除线、上下标、项目符和本地图片。
- 开启“链接开关”，点击“点击此链接”查看应用内回调；关闭后可定位光标编辑。
- “运行自检”核对文本、选区、事件、图片读取和异常分支，结束后恢复样式演示。

格式直接作用于当前编辑内容。索引从 0 开始，采用 UTF-16 半开区间 [开始,结束)，结束位置不包含；表情可能占两个索引。字号单位为 SP，图片尺寸单位为 DIP。项目符作用于选中内容涉及的完整段落；清除格式保留图片、移除相关段落项目符。空字符区间不改变样式，图片区间必须非空。

读取“文本”仅返回纯文本；本组件不提供 HTML 导入导出、富文本存盘或完整文档排版。“创建风格文本”及直接重设“文本”会清除旧格式；追加和区间编辑保留已有格式，图片重叠时整体替换旧图片。

图片取自 assets/simple.png，无需网络或存储权限。外部文件需由应用自行取得访问条件；不下载网络图片。链接只派发事件，不自动打开浏览器。
