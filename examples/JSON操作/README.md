# JSON操作

使用 IP 与 DNS 响应学习嵌套对象、数组、类型读取和内容修改。

运行准备见[项目说明](../../README.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 默认载入离线 IP 响应；点击“取属性名”和“取值”，读取根对象与嵌套的 `data`。
2. 切换为 DNS 样本，观察 `records` 对象数组及记录值、TTL。
3. 点击“置值”，查看新增的文本、逻辑、null 和混合数组字段。
4. 可选点击“在线查询 IP”读取实时响应；损坏输入后可用样本按钮恢复。

离线样本按 [TCPLab API](https://tcp.lc/zh/page/api) 响应结构编写，记录值仅作演示。实时查询需要联网；HTTP 200 仍须检查业务状态 `code`。
