# 对象与接口

定义接口、实现对象，并演示对象引用与窗口消息。

运行准备见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 点击“创建接口实现对象”，查看接口函数返回的问候文本与接口常量。
2. 点击“变量与文本”和“对象引用”，比较普通变量输出与对象实际类型。
3. 点击“投递窗口消息”，查看反馈消息日志，再清空日志。

对照 [示例接口.simple](src/simple/examples/objects/示例接口.simple) 与 [示例对象.simple](src/simple/examples/objects/示例对象.simple)。
