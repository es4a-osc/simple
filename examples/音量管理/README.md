# 音量管理示例

演示“音量管理器”非可视组件的系统音量读取、设置、最大档位查询和有线耳机检测，支持系统提示音、通话、铃声、媒体及闹钟五种类型。

在 ES4A 添加本目录的 [project.properties](project.properties)，使用包含该组件的运行库编译运行。源码：[主窗口](src/simple/examples/volume/主窗口.simple)。

1. 默认选择媒体，点击“读取当前与最大音量”核对档位及有线耳机连接状态。
2. 输入有效整数档位，点击“设置并回读”，比较请求值与系统实际值；“只读自检全部类型”不改变音量。
3. 测试后点击“恢复所选类型原音量”。初始值只在本次启动时记录，退出应用不会自动恢复。

组件声明 `MODIFY_AUDIO_SETTINGS` 普通权限，无需运行时请求。触发勿扰模式变化可能需要用户在系统设置中单独授予通知策略访问权限；示例不申请该访问权限，也不主动调用勿扰设置接口。固定音量设备、通话及系统策略可能忽略或限制设置，须读取确认。

音量是设备定义的整数档位，不是百分比；设置会影响使用同一音频流的其它应用。有线检测包含系统明确识别的 USB 耳机，不包含蓝牙，也不能证明当前播放路由。真实耳机插拔与设备声音效果需要实机验证。

验证状态：已通过 APK 编译和 Android 14 模拟器测试，覆盖五类音量读取、媒体设置与回读、原档位恢复、类型切换及非法输入拒绝；媒体档位和勿扰状态已恢复或保持原值。未验证真实耳机插拔、实际声音效果及旧系统。
