# 弹出菜单

文档类型：运行库使用示例。核对日期：2026-10-19；依据：当前组件源码、运行库清单与本项目。

动态项目和 XML 菜单资源的独立示例。打开本目录的 [project.properties](project.properties)，编译并运行。

- 点击“弹出动态菜单”，查看排序后的项目，展开“更多操作”并选择子项。
- 点击“弹出资源菜单”，加载 [demo_menu.xml](res/menu/demo_menu.xml)，选择项目后核对日志。
- 点击“删除一个动态项目”，重新弹出时应不再显示该项；“清空”与“重建”用于重新组织动态菜单。
- 选择项目、点击菜单外部或按返回键，观察选中与关闭事件。初始化和重建时会验证分组、排序及父子关系。

菜单项使用标识访问，0 表示顶层或未分组。动态项目修改在下一次弹出时显示；删除父项同时删除其子项。设置有效菜单资源会清空动态项目，添加动态项目会切回动态模式。空菜单不弹出，也不触发关闭事件。展开父项时，系统可能先回调父项标识，子项选择另行回调。锚点必须是当前窗口已附着的可视组件，布局尚未建立时不能弹出。

组件本身不需要权限或第三方依赖。示例入口：[主窗口](src/simple/examples/popupmenu/主窗口.simple)。

验证状态：已基于当前源码生成 APK，并在 Android 14 / API 34 模拟器验证动态菜单、资源菜单、普通项和子项回调、排序、删除、清空与重建，以及返回键和菜单外部关闭。测试结束回到示例主窗口，菜单已关闭；真机及其他 Android 版本尚未验证。
