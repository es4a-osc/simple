# 字节集操作

演示字节数组的长度、合并、左右及中间截取、多字节分割与错误捕获，无需联网或权限。

在 ES4A 添加本目录的 [project.properties](project.properties)，使用包含这些接口的运行库编译运行。源码见[主窗口](src/simple/examples/bytesets/主窗口.simple)，项目说明见 [Simple 仓库](../../README.md)。

- **字节合并与截取**：以 ABCD 验证长度、三个截取方向及合并；修改返回数组后核对原数组没有变化。
- **多字节分割与空片段**：使用两个竖线分割，显示每个片段内容和字节数，核对连续分隔符与末尾不完整匹配。
- **边界错误与空数据**：捕获越界起点、负长度和空分隔符，验证超长截取与空内容。

索引从 0 开始，长度以字节计。截取数量超过剩余数据时取到末尾；起点等于总长度时返回空数组，越界起点和负数量会抛出错误。

分割按不重叠的字节序列匹配，保留首尾、连续分隔符产生的空片段；空原数据得到一个空片段。分隔符不得为空。返回集合的每个项目是一个字节数组，可赋给字节数组变量使用。

合并、截取、分割返回独立的字节数组，不修改原数据。字符集转换使用文本到字节、字节到文本，默认 UTF-8；按字节截取可能截断多字节字符，不能直接当成文本字符截取。
