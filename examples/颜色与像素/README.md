# 颜色与像素

文档类型：运行库使用示例。核对日期：2026-10-17；依据：当前 Simple 编译器、运行库源码与本项目。

ARGB 颜色、通道分解与 DIP、像素转换。

运行准备与完整目录见[示例入口](../../README.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/colors/主窗口.simple)。

1. 输入 `#336699`，点击“解析颜色与换算尺寸”，查看色块、颜色通道及自检结果；透明度应为 255，红、绿、蓝分别为 51、102、153。
2. 改为 `#80336699` 或 `#00336699` 再次运行，透明度分别为 128、0，其他颜色通道保持不变。输入非法文本时会显示格式提示。

支持六位 `#RRGGBB` 和八位 `#AARRGGBB`，十六进制字母不区分大小写。六位格式默认完全不透明；各分量范围为 0–255，透明度 0 为完全透明、255 为完全不透明。DIP 和物理像素随设备密度变化。

验证状态：已使用当前运行库源码编译 APK，并在 Android 14 / API 34 模拟器验证两种格式、透明度、大小写及非法输入提示；真机尚未验证。
