# 文件读写

演示应用私有目录中的句柄读写、普通文本与字节文件、复制改名、目录枚举和文件信息查询。

在 ES4A 中添加本目录的 [project.properties](project.properties)，编译运行。源码见[主窗口](src/simple/examples/files/主窗口.simple)，项目使用说明见 [Simple 仓库](../../README.md)。需要包含新增文件接口的运行库。

- **句柄与二进制读写**：演示打开文件、写入文本、移动文件指针、读入文本、关闭文件等接口，按相同类型和顺序重新读取，再改名并清理两个固定文件。
- **普通文本与编码**：使用 UTF-8 默认编码和指定 GBK 编码读写中文。普通文本与“写入文本”的二进制 UTF 格式不同；写文本不会自动添加 BOM，读文本也不自动移除 BOM。取文件编码只识别 BOM，没有 BOM 返回空文本，不猜测实际编码。
- **字节读写与文件管理**：复制后逐字节核对内容，再演示改名、尺寸查询和删除。复制会覆盖目标；改名不覆盖已有目标。
- **目录枚举与文件信息**：创建多级目录，查询下一级文件、子目录、隐藏状态和修改时间。目录列表返回排序后的绝对路径文本数组；尺寸以字节计，目录尺寸递归累计文件，不遍历目录符号链接。
- **存储空间查询**：直接查询私有 files 目录所在卷，或在路径框填写已有文件、目录（默认为 `.`）后查询其所在卷。两个查询均返回长整数型字节数；文件路径统计的是所在卷，不是文件大小。
- **错误处理**：验证复制自身、无效编码和读取缺失文件会失败，已有文件内容不变。操作错误可通过 Simple 的“位于 错误”处理，不把读取失败当作空文件。
- **清理本例目录**：递归删除本例创建的 es4a-file-example 目录；删除不可恢复，中途失败可能已删除部分内容。可以重复运行并清理。

相对路径以应用内部私有 files 目录为基准，无需存储权限。示例的写入和清理仅操作 es4a-file-example 目录，以及句柄演示中的 es4a-example.bin、es4a-example-renamed.bin；空间查询可指定其他已有路径，不修改目标。新增路径接口接受绝对文件路径，但仍受 Android 授权限制，暂不支持 content URI；不会自动申请公共存储权限。创建目录会补建父目录，写文件与复制则要求目标父目录已存在。整文件读取会占用对应内存，大文件应使用分段处理。

存储空间查询不创建探测文件，也不新增权限。可用空间采用系统对普通应用报告的估计值，不包含 root 保留空间；应用配额、目录写权限等限制未必体现在数值中，空间也会随其他程序活动变化，不能保证后续写入成功。没有空间或系统无法提供统计时可能返回 0；缺失路径按现有接口抛出文件未存在错误，无效路径和 content URI 被拒绝。

验证状态（2026-10-18）：空间查询已通过主机路径回归与真实示例编译。Android 14 / API 34 模拟器验证默认目录、相对文件、中文目录和绝对文件路径查询，返回超过 2 GB 的长整数容量；总空间与系统统计一致。缺失路径和 content URI 被拒绝。独立存储卡、配额、空间耗尽及其他 Android 版本未实测。
