# XML处理

演示运行库 XML解析器、XML生成器两个普通对象，无需额外权限或第三方依赖。

1. 点击“生成与解析示例”，查看包含中文、命名空间、属性、空节点及混合文本的 XML。
2. 点击“边界与错误自检”，验证 UTF-8、UTF-16、GB18030 的自动识别与指定编码往返，以及对象隔离、CDATA、16 种错误分支和失败后重新开始。重复点击可再次运行。

解析器在设置输入后位于文档开始位置，只有“读取下一个”推进节点。名称是本地名称，命名空间按 URI 区分；属性索引从 0 开始。“取节点内容”仅返回当前位置的文本，不自动读取子元素。

生成器必须显式结束所有节点再结束文档。文本与属性内容自动转义，不传入已转义的 XML 片段。需要写文件或发送网络数据时优先使用“导出字节集”；“导出文本”是已经解码的字符串，再保存时应保持声明编码一致。

格式、状态和编码错误抛出 XML错误，可在错误分支调用对应对象的“取错误信息”查看原因。每个对象单独使用，不跨线程同时操作；支持普通 XML 流式读写，不提供 XPath、DTD 验证或原始排版无损往返。

运行准备见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。
