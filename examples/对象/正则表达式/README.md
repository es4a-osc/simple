# 正则表达式

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

编译表达式、查找分组、位置、替换与分割。

运行准备与完整目录见[项目说明](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/regex/主窗口.simple)。

1. 点击“运行演示与自检”，查看输出和校验结果；操作顺序直接写在主窗口的按钮事件中。
2. 再次运行，确认没有沿用上一轮的临时状态。

使用当前正则表达式对象 API。位置从 0 开始，结束位置不包含在匹配区间内；分组 0 是整个匹配，捕获组从 1 开始。Simple 文本中反斜杠需要转义，例如数字模式写作 `"\\d+"`。 本例直接使用 `表达式.匹配(待匹配文本)`；参数是文本，不需要反射调用使用的变体数组。“匹配”与语言运算符同名，需要使用已支持点号关键字成员访问的编译器。仓库验证使用本次构建的 `dist/windows/`；尚未更新的 SDK 编译器会报告“需要标识符”。

验证状态：已通过 APK 编译。按钮事件中的断言检查演示结果；Android 真机操作和扩展宿主可见交互尚待验证。
