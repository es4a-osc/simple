# 集合与哈希表

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

有序集合、按键取值、覆盖键和无序迭代。

运行准备与完整目录见[示例入口](https://gitee.com/es4a/sdk/blob/main/docs/Simple项目开发.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/collections/主窗口.simple)。

1. 点击“运行演示与自检”，查看输出和校验结果；操作顺序直接写在主窗口的按钮事件中。
2. 再次运行，确认没有沿用上一轮的临时状态。

集合索引从 0 开始；哈希表不保证顺序。先调用 `是否包含键` 再取值；迭代期间不要通过普通加入、删除方法修改表。

验证状态：已通过 APK 编译。按钮事件中的断言检查演示结果；Android 真机操作和扩展宿主可见交互尚待验证。
