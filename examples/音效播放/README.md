# 音效播放

演示预加载短音效、单次播放、多路循环、暂停继续、停止、卸载和释放后重新初始化。无需联网或额外权限，两个 WAV 为本示例生成的短纯音；invalid.wav 专门用于失败检查。

1. 点击“初始化并载入”，等待两条成功事件。载入的音效编号与每次播放得到的播放编号分别保存在不同变量中。
2. 点击“单次播放音效一”或“双音效循环播放”，再尝试暂停、继续和停止；暂停、继续、停止均传播放编号。
3. “卸载音效一”检查旧音效不能再次播放；“释放播放器”可重复调用，再初始化后须重新取得编号。
4. “快速重建检查”在同一次操作内连续重建两次，只应收到最终一轮的两条成功事件。
5. “检查加载失败”覆盖不存在的文件、无效编号、无效循环次数及损坏音频。同步打开失败返回 -1；取得编号后的异步失败显示系统状态。

播放一次使用单参数重载；循环次数 0 表示播放一次，-1 表示持续循环，正数表示额外重复次数。系统不会报告每个短播放流的自然结束，过期播放编号的控制操作由系统忽略。

SoundPool 适合预加载短音效，长音乐使用音频播放器；不支持网络地址或 content URI，外部绝对路径仍受系统文件访问限制。测试结束请停止循环或释放播放器。运行准备见[项目说明](../../README.md)。
