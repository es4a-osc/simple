# 文件选择

使用系统文档选择器导入和保存文件，无需第三方库或广泛存储权限。返回的是 content URI，可直接读写，或复制成应用私有路径供现有类库使用。

本示例依据当前运行库文件选择器编写，2026-10-18 在 Android 14 完成验证；其它系统版本和云端文档提供方尚未实测。

- “选择并读取 XML”：选择 UTF-8 编码的 XML，读取字节并交给 XML解析器验证；其它编码应按文档实际编码传入解析器。
- “选择多个文本文件”：第二个组件实例按 text/* 类型筛选，展示多选结果；是否能多选由系统提供方决定。
- “创建并写入 XML”：由用户确定保存位置，写入后覆盖为较短 XML 并回读，核对截断无残留。同名文件可能被系统重命名，不承诺覆盖已有文件。
- “导入文件到私有目录”：复制到本例私有 picker-import.bin，返回绝对路径。可将它直接传给 EXCEL操作.读取工作表；现有 EXCEL 库只支持 .xls，不支持 .xlsx。复制会覆盖本例私有同名文件，不覆盖用户选择的源文件。
- “选择目录并创建示例”：授权选定目录，创建 es4a-picker-child.xml 并读写、列出子项。再次运行可能生成重命名文件，不会删除用户文件。
- “重新读取保留文档”：先保留授权并保存 URI，可重启应用后重新读取；失效时仍需重新选择。“释放本例授权”只释放本例保存的两个 URI，不删除数据。
- 按返回键取消系统选择，再次打开应正常；“检查错误分支”演示无效 MIME 与物理路径不会被当作授权 URI。

文件选择及持久授权要求 Android 4.4，目录要求 Android 5.0；低版本明确报告不支持，不提高其它运行库功能的最低版本。初始 URI 仅在 Android 8.0 起作为提示，系统可忽略。界面外观、文件来源、可访问目录、读写能力、网络可用性和未知大小均由系统及文档提供方决定。

同步读取可能需要下载云文件；大文件应在工作线程流式复制，避免界面阻塞或完整读入内存。字节写入失败可能已修改部分文档，不保证远端原子提交。复制的相对目标路径以应用私有 files 目录为基准，绝对目标路径仍受系统文件权限限制。

每个组件同时只发起一个请求，多个实例的回调互不混用。应用进程被系统回收后，不承诺恢复尚未返回的选择请求；主动保留的文档授权可配合已保存 URI 在下次启动时使用，文件移动、删除或用户撤权仍可能使其失效。
