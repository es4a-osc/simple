# 图片按钮

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

图片按钮的单击、长按、按下弹起和启用状态。

运行准备与完整目录见[示例入口](../../README.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/imagebutton/主窗口.simple)。

1. 单击和长按图片按钮，比较事件。
2. 按下再移开，查看坐标日志。
3. 禁用按钮后确认不再触发普通单击，再启用。

复用项目图标资源；图片按钮继承图片组件，不提供文本组件的文字属性。触摸坐标由当前 Android 视图回调提供，不把它当作 DIP 坐标换算接口。

验证状态：已通过 APK 编译。Android 真机操作和扩展宿主可见交互尚待验证。
