# 剪贴板操作

演示系统剪贴板的纯文本写入、读取与非空判断，无需额外权限或第三方依赖。

在 ES4A 添加本目录的 [project.properties](project.properties)，使用包含剪贴板操作接口的运行库编译运行。源码见[主窗口](src/simple/examples/clipboard/主窗口.simple)，项目说明见 [Simple 仓库](../../README.md)。

- 修改输入框，点击“复制输入文本”，再点击“读取剪贴板文本”，核对中文、换行及前后空白。
- 点击“判断是否有文本”；空格和换行也属于非空文本。
- 点击“写入空文本”，再读取和判断，应得到长度 0 和假；这只是覆盖为空文本项目，不是清除剪贴板。
- 点击“验证五组文本”，验证中文、换行、空白、表情及空文本的往返与判断，共 10 项断言。该操作会覆盖剪贴板，最后留下空文本项目。

只读取第一项现成文本，不读取 URI、图片、意图或历史记录，不进行文件加载；富文本只返回文字内容。程序启动、恢复和后台不会自动读取或监听剪贴板，也不记录或缓存读取内容。

读取遵守 Android 的输入焦点与隐私限制。没有内容、第一项不含文本或系统禁止读取时，取剪贴板文本返回空文本，剪贴板是否有文本返回假；不能据此断定系统剪贴板为空。系统可能显示复制或读取提示，内容也可能在两次调用之间变化。请在应用具有输入焦点时由用户主动操作，不要复制密码等敏感信息。

验证状态（2026-10-18）：示例 APK 1.0（版本号 1）已在 Android 14 / API 34 模拟器验证，中文复制、读取、非空判断、空文本分支、系统原生粘贴及五组文本共 10 项往返断言通过。未验证其他 Android 版本、非文本外部项目及后台受限读取；本方法集尚未发布到 SDK JAR。
