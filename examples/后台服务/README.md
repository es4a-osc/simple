# 后台服务

从窗口发送服务意图，在服务中处理并反馈结果。

运行准备见[项目说明](../../README.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 点击“通过服务查询我的 IP”，观察任务提交、服务创建和查询结果。
2. 输入 `8.8.8.8`，点击“查询指定 IP”，观察任务参数如何通过意图传递。
3. 对照服务单元中的处理过程；任务结束后由系统销毁服务。

任务实现见 [任务服务.simple](src/simple/examples/service/任务服务.simple)。

查询接口见 [TCPLab API](https://tcp.lc/zh/page/api)。服务生命周期由系统管理；应用进入后台后的行为还受设备系统限制。
