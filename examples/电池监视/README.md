# 电池监视示例

使用运行库“电池监视器”读取电量、充电状态、温度、电压、外部电源和健康状态，无需额外权限或第三方依赖。

打开 project.properties 编译运行。默认启用监听，首次取得信息及任一公开数据变化时更新页面和事件次数。点击“读取当前结果”显示缓存，“停止监听”保留最后结果，“启用监听”重新读取最新状态；重复启用不会重复注册。“销毁监视器”释放监听，销毁后不能重新启用，关闭并重新打开应用可重新演示。

电量为 0 至 100 的整数百分比，未知或无电池时为 -1；温度单位是摄氏度，电压单位是伏，未报告的测量值为 NaN。外部电源类型与电池是否正在充电是不同信息；“是否可用”不保证所有可选测量值都有值。

可通过连接或断开电源观察状态变化；模拟器报告的是模拟电池数据，不能替代真机温度、电压和健康状况验证。监听依赖当前进程，系统决定广播时机，不提供持续后台运行保证。
