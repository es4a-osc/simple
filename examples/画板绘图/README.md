# 画板绘图

演示手绘连线、图形与文字、图片绘制、像素读取及 PNG/JPEG 保存。打开 project.properties，使用包含本组件接口的运行库编译运行，无需额外权限或第三方依赖。

## 使用示例

- “拖动画线”：按住并移动，连续绘制线段。
- “按点连线”：依次点击不同位置，连接相邻点。
- “图形、图片、取点与保存”：点击绘制按钮查看图形、文字和图片；点击验证按钮执行固定像素与文件结果自检。返回键或返回按钮回到主菜单。

图形页会绘制矩形、圆角矩形、椭圆弧、二次贝塞尔曲线和单行文字。通过画笔_描边、画笔_填充切换画笔类型；字号与线宽都是绝对像素 px。自带的 pixel-sample.png 为 16×16 的红蓝测试图片，用来比较原始尺寸与指定尺寸绘制。

## 坐标与画面

绘图坐标和触摸坐标均相对于画板左上角，使用 px，不按屏幕密度自动缩放。矩形和图片接口的最后两个整数表示宽、高；文字的 y 是基线，不是文字顶边。圆弧正右方为 0 度，正角度顺时针，连接圆心时形成扇形。

取点颜色返回画面实际 ARGB 值，包含画板背景和绘制内容，不包含其它组件或边距。坐标越界抛出索引超出界限错误。取点和保存需要等布局完成；示例使用计时器等待实际尺寸，而非在初始化事件中假设布局已经完成。

修改画板尺寸保留左上交集区域；缩小会裁掉超出新边界的内容，重新放大不恢复已裁去的像素。清空或设置背景颜色会按当前背景色重置整个画面，画笔设置保持不变。所有画板接口都应在界面线程调用。

## 图片与保存

画图片支持资产文件名及可访问的绝对文件路径，不支持网址、资源标识或 content URI。无宽高重载按原始像素绘制；指定宽高的重载会缩放，不自动保持比例。读取或解码失败抛出文件读写错误。

保存画面(路径) 默认使用 PNG；保存画面(路径, 格式) 支持图片格式_PNG 和图片格式_JPEG。文件后缀不决定编码。PNG 保留透明度；JPEG 使用白色衬底、质量 100。保存的是实际布局大小的画板，不包含页面按钮或其它组件。

相对保存路径以应用私有 files 目录为基准，父目录须已存在，同名文件会覆盖。绝对路径仍受 Android 访问限制，组件不申请存储权限。自检生成 canvas.png、canvas.jpg 和 canvas-size.png，可重复运行；失败读写不会假装保存成功，抛出文件读写错误。

自检覆盖填充与描边、清空、图片尺寸和颜色、透明度、文件格式与尺寸、缩小后再放大、越界、错误参数、图片读取失败、保存失败及重复销毁。模拟器可以验证上述像素和文件结果；文字字形和抗锯齿效果随系统字体与绘制实现有所不同。
