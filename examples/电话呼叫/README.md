# 电话呼叫

演示电话能力和 SIM 状态查询、系统拨号、直接呼叫、通话状态监听、本机号码读取、振动及通话记录操作。

在 ES4A 中添加本目录的 [project.properties](project.properties)，编译运行。源码见[主窗口](src/simple/examples/phone/主窗口.simple)，项目使用说明见 [Simple 仓库](../../README.md)。需要包含上述接口的新版运行库。

1. 在下拉列表选择操作；需要参数时，在参数框填写卡槽索引、振动毫秒数或通话记录编号。
2. 点击“申请所选操作权限”，查看实际授权结果后再点击“执行所选操作”。拒绝权限时可以重新申请或打开应用权限设置；通话记录权限可能受系统及安装来源限制而无法授予。
3. “开始监听”会返回当前状态及后续变化；0 为空闲、1 为响铃、2 为摘机。摘机包括拨号，不表示对方已接听。来电号码可能为空。“停止监听”可重复调用，组件销毁时也会清理监听。“释放电话组件”演示重复销毁与资源清理，之后需选择“退出示例”并重新打开才能继续使用。
4. “打开系统拨号界面”只预填下面号码框的内容，不自动拨号。直接呼叫需另行申请呼叫权限、填写自己的测试号码并勾选确认，可能产生费用。
5. 振动参数为毫秒，0 停止，负数进入错误处理；设备没有振动器时不能振动。SIM 卡槽从 0 开始，指定卡槽查询需要 Android 8.0；本机号码未写入 SIM 卡或系统不提供时返回空文本。Android 7.1 及以下读取号码可先选择“查询通话状态”申请电话状态权限。
6. 通话记录最多返回最近 100 条，每项为文本数组：`[记录编号、号码、缓存联系人名、类型、时间戳毫秒、时长秒]`，类型使用系统值，如 1 来电、2 去电、3 未接。删除时填写记录编号并勾选确认，只删除这一条；不要填写电话号码。此操作不可恢复。

电话能力、SIM 卡就绪、权限授权和实际通话成功是不同条件，应分别检查。模拟器可用于验证权限、界面与事件流程，真实通话及振动效果需在设备上确认。
