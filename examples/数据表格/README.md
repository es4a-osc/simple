# 数据表格

展示 SQLite 查询结果、行列操作、行标记、表格样式和本地图片首列。

使用包含“数据表格”的运行库及配套清单，打开本项目后按 F5 编译运行。

1. 启动后显示应用私有 SQLite 数据库中的三条示例记录，点击数据行选中。
2. 用“追加一行”“修改选中”“删除选中”操作界面数据；没有选中时修改和删除第一行。
3. 点击“切换样式”查看已有行的样式变化；“图片列”使用 APK 自带的 simple.png。
4. “宽表滚动”载入 12 行、8 列数据，在表格内左右或上下滑动。
5. “清空表格”移除表头和数据；“重新载入”恢复示例数据库内容。“运行自检”检查公开接口后恢复初始记录。

行列索引从 0 开始，表头不计入行数，越界会报告索引超出界限错误。显示图片时，数据首列为资源、资产或可访问文件的图片标识；不下载网络图片，文件访问仍受系统存储规则限制。

示例界面修改不回写数据库，重新载入会重建本示例的数据。演示查询使用固定、不含竖线或换行的内容进行分隔，不是通用数据序列化格式。

组件按内容建立原生表格，适合中小规模展示，不提供单元格输入、排序、分页或大数据虚拟滚动。大量数据应由应用分页后填充。
