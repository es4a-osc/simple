# 蓝牙通信

文档类型：运行库使用示例。核对日期：2026-10-16；依据：当前 Simple 编译器、运行库源码与本项目。

经典蓝牙配对列表、搜索、聊天监听与字节收发。

运行准备与完整目录见[项目说明](../../README.md)。在 ES4A 添加本目录的 [project.properties](project.properties)，保存后选择“编译应用”或“调试应用”。源码：[主窗口](src/simple/examples/bluetooth/主窗口.simple)。

1. 先请求权限，在系统设置完成蓝牙开启和配对。
2. 列出配对设备，将 MAC 地址填入输入框。
3. 使用另一台本例时，两端先启动聊天模式；连接串口模块时保留默认串口模式。
4. 收到连接成功事件后发送固定字节 Hi 换行，对端检查字节片段。
5. 停止搜索、断开连接后退出。

默认主动连接使用串口 UUID；两台本例聊天时，应先各自切换聊天模式，再由一端连接。搜索请求被系统拒绝时进入错误分支，监听失败通过连接完毕事件返回失败；销毁会停止搜索并清理连接和监听。当前编译器生成的应用目标 API 为 26，使用蓝牙与定位权限；目标 API 提升至 31 或以上时，需要同时适配附近设备权限，不能只根据手机系统版本判断。

验证状态：已在 Android 14（API 34）完成权限、配对列表、设备发现、搜索停止及失败反馈的 APK 自动化验证；双端 RFCOMM 连接和字节收发尚待配套设备实测。
