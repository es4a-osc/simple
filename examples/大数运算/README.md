# 大数运算示例

演示运行库“大数运算”的加、减、乘、除、比较、求余，以及“文本操作”的科学计数展开，无需权限或第三方依赖。

输入两个数值文本，选择运算后点击“计算”；科学计数展开仅使用数值一，小数位数仅用于除法。“运行固定结果自检”核对 6 个大数运算接口及 1 个文本展开接口的精度、格式、舍入和异常。

- 大数直接以文本传入；例如 `9007199254740993 + 1` 得到 `9007199254740994`，`0.1 + 0.2` 得到 `0.3`。先转为普通浮点数会丢失精度。
- 输入支持正负号、小数及科学计数，不自动去除空白；结果不带指数，不主动删除小数末尾零。
- 除法使用 HALF_UP，中间值向远离零方向舍入；`-1.005` 保留两位为 `-1.01`。位数为 0 表示整数，-2 表示舍入到百位。
- 比较返回 -1、0 或 1，`1.0` 与 `1.00` 相等；非零余数与被除数同号，`-5` 除以 `3` 的余数为 `-2`。
- 非法文本、空引用和除零保留异常；非法文本由示例的错误分支显示提示。现有 Simple 错误转换不能接住 Java 算术异常，示例在除法和求余前使用大数比较检查零除数；直接调用时也应先检查。处理规模受可用内存限制。

在 ES4A 项目视图中添加本目录的 `project.properties`，使用包含“大数运算”及“文本操作.科学转普通计数”的运行库编译运行。
