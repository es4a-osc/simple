# TCP服务端

监听 TCP 端口，接收客户端字节并原样回显。

运行准备见[项目说明](../../README.md)。在 ES4A 中打开本项目，按 `F5` 编译运行。

1. 保留监听端口 `5001`，点击“开始监听”。
2. 运行配套 TCP 客户端：同机使用 `127.0.0.1`，跨设备使用服务端局域网地址。
3. 客户端连接并发送后，观察来源地址、收到的字节及回显日志。
4. 结束时先断开客户端，再关闭监听。

配套示例：[TCP客户端](../TCP客户端/README.md)。

TCP 是字节流，一次接收不代表一条完整消息。组件没有监听成功回调，“已请求监听”需通过客户端连接验证；关闭监听不会代替客户端断开。
